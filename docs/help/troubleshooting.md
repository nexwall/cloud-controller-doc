# Troubleshooting

**The firewall does not appear after pasting the join code.** Check that the firewall has internet access and the correct date and time, and that you pasted the whole code. Generate a new code from **Add firewall** and try again.

**The firewall shows "Not connected".** The VPN connection to the controller is down: check the firewall's internet connection and that the controller address is reachable. The status turns to *Connected* a minute after the connection is back.

**"Not registered".** The firewall joined but has not sent its first data yet. Use **Sync firewall info** from the actions menu.

**I cannot open the firewall or the terminal.** Allow pop-ups for the controller site. If the firewall needs an update before it can be opened, update it first (see [Updates](../firewalls/updates.md)). If direct access fails in the terminal, use the firewall password or your own key passphrase.

**A report failed.** The firewall may be offline or busy; the controller retries automatically. Generate it again later, with fewer firewalls at a time.

**I forgot my password.** Ask an administrator of the controller to reset it, or, if you reach the controller through the Partner Portal, use **Open in controller**.

Still stuck? Contact Nexwall support from the Partner Portal.
