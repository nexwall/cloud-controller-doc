# Updates

The controller can update firewalls remotely. From the actions menu of a firewall:

- **Image update**: when a new version is available the firewall shows *Image update available*. You can install it now or **schedule** it for a date and time; a scheduled update shows *Image update scheduled* and can be edited or cancelled. The firewall can be unavailable for a few minutes while it installs.
- **Check packages updates**: lists the packages that can be updated and lets you apply them.

To update several firewalls at once, select them in the list and use the batch update action. Firewalls that fail are listed so you can try them again.

Plan updates outside business hours: during an image update the firewall restarts and the customer network may lose connectivity for a few minutes.
