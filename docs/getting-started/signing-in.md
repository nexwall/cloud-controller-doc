# Signing in and the interface

1. Open the address of your controller (for example `https://your-company.painel.nexwall.com.br`).
2. Sign in with your controller user name and password. If your user has two-factor authentication (2FA) enabled, enter the code from your authenticator app.
3. You land on the **Firewall manager**.

From the Partner Portal you can skip the sign-in: the **Open in controller** button signs you in automatically for a short time.

<Shots items={[{"name": "login", "caption": "The sign-in page of the controller."}]} />

The left menu has the Firewall manager, Firewall groups, Reports, Users and Account settings. The top bar has the language, the light and dark theme and the help button: **the help button opens the page of this guide that explains the screen you are on**.

You can change the interface language in [Account settings](../administration/account-settings.md).
