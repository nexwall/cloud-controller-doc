# Solução de problemas

**O firewall não aparece depois de colar o código de adesão.** Verifique se o firewall tem acesso à internet e data e hora corretas e se você colou o código inteiro. Gere um novo código em **Adicionar firewall** e tente novamente.

**O firewall aparece como "Não conectado".** A conexão VPN com o controlador está interrompida: verifique a conexão do firewall com a internet e se o endereço do controlador está acessível. O status volta para *Conectado* cerca de um minuto depois que a conexão retorna.

**"Não registrado".** O firewall entrou, mas ainda não enviou os primeiros dados. Use **Sincronizar informações do firewall** no menu de ações.

**Não consigo abrir o firewall nem o terminal.** Permita pop-ups para o site do controlador. Se o firewall precisa de uma atualização para ser aberto, atualize-o primeiro (veja [Atualizações](../firewalls/updates.md)). Se o acesso direto falhar no terminal, use a senha do firewall ou a frase secreta da sua chave.

**Um relatório falhou.** O firewall pode estar offline ou ocupado; o controlador tenta novamente de forma automática. Gere-o de novo mais tarde, com menos firewalls por vez.

**Esqueci a minha senha.** Peça a um administrador do controlador para redefini-la ou, se você chega ao controlador pelo Portal de Parceiros, use **Acessar o controlador** (na página do cliente) ou **Abrir no controlador** (na lista de Firewalls).

Ainda com dúvidas? Fale com o suporte da Nexwall pelo Portal de Parceiros.
