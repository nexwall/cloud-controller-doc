# Atualizações

O controlador pode atualizar firewalls remotamente. No menu de ações de um firewall:

- **Atualização de imagem**: quando há uma nova versão, o firewall mostra *Atualização de imagem disponível*. Você pode instalá-la agora ou **agendá-la** para uma data e hora; uma atualização agendada mostra *Atualização de imagem agendada* e pode ser editada ou cancelada. O firewall pode ficar indisponível por alguns minutos durante a instalação.
- **Verificar atualizações de pacotes**: lista os pacotes que podem ser atualizados e permite aplicá-los.

Para atualizar vários firewalls ao mesmo tempo, selecione-os na lista e use a ação de atualização em lote. Os firewalls que falharem são listados para você tentar novamente.

Planeje as atualizações fora do horário comercial: durante uma atualização de imagem o firewall reinicia e a rede do cliente pode perder a conectividade por alguns minutos.
