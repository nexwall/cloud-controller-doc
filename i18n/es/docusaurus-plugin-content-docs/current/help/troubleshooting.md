# Solución de problemas

**El firewall no aparece tras pegar el código de unión.** Comprueba que el firewall tiene acceso a internet y la fecha y hora correctas, y que pegaste el código completo. Genera un código nuevo en **Añadir firewall** e inténtalo de nuevo.

**El firewall aparece como "No conectado".** La conexión VPN con el controlador está caída: revisa la conexión a internet del firewall y que la dirección del controlador sea accesible. El estado vuelve a *Conectado* alrededor de un minuto después de recuperar la conexión.

**"No registrado".** El firewall se unió pero aún no ha enviado sus primeros datos. Usa **Sincronizar información del firewall** en el menú de acciones.

**No puedo abrir el firewall ni el terminal.** Permite las ventanas emergentes del sitio del controlador. Si el firewall necesita una actualización para poder abrirse, actualízalo primero (consulta [Actualizaciones](../firewalls/updates.md)). Si el acceso directo falla en el terminal, usa la contraseña del firewall o la frase de contraseña de tu clave.

**Un informe falló.** El firewall puede estar sin conexión u ocupado; el controlador reintenta automáticamente. Vuelve a generarlo más tarde, con menos firewalls a la vez.

**Olvidé mi contraseña.** Pide a un administrador del controlador que la restablezca o, si llegas al controlador desde el Portal de Socios, usa **Acceder al controlador** (en la página del cliente) o **Abrir en el controlador** (en la lista de Firewalls).

¿Sigues atascado? Contacta con el soporte de Nexwall desde el Portal de Socios.
