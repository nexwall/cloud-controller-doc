# Actualizaciones

El controlador puede actualizar firewalls de forma remota. Desde el menú de acciones de un firewall:

- **Actualización de imagen**: cuando hay una versión nueva, el firewall muestra *Actualización de imagen disponible*. Puedes instalarla ahora o **programarla** para una fecha y hora; una actualización programada muestra *Actualización de imagen programada* y se puede editar o cancelar. El firewall puede quedar no disponible unos minutos durante la instalación.
- **Buscar actualizaciones de paquetes**: muestra los paquetes que se pueden actualizar y permite aplicarlos.

Para actualizar varios firewalls a la vez, selecciónalos en la lista y usa la acción de actualización por lotes. Los firewalls que fallen se listan para que puedas reintentarlo.

Planifica las actualizaciones fuera del horario laboral: durante una actualización de imagen el firewall se reinicia y la red del cliente puede perder conectividad unos minutos.
